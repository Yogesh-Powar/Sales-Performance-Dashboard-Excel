# Sales Performance Dashboard | Microsoft Excel

## Project Overview

An interactive Sales Performance Dashboard developed using Microsoft Excel
to analyze retail sales performance and generate business insights.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Tables
- Helper Columns
- Data Cleaning

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Sales by Region
- Profit by Region
- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Top 10 Products
- Sales by Segment
- Interactive Slicers

## Business Analysis

The dashboard helps analyze sales and profitability across different
regions, categories, segments, products, and time periods.

Users can apply slicers to dynamically filter the dashboard and explore
different aspects of sales performance.
